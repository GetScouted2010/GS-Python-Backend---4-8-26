<note_on_tfm_helper>
Plan 01's `compare_tfm_series(oracle_log, port_money)` expects the PORT side already in money scale and the ORACLE side in log scale. For the bulk check the port side is ALSO log-scale (raw predict). So call `compare_series(oracle_tfm_log, port_tfm_log, rtol=...)` is NOT ideal on log scale. Instead: convert the port's raw log-scale prediction to money once (`np.expm1`) and pass to `compare_tfm_series(oracle_log=oracle["tfm"], port_money=np.expm1(port_log))`. That helper converts the oracle log column to money internally, so both sides end up money-scale and the 0.1% relative bound is applied on money — exactly CONTEXT.md's locked TFM tolerance. This is the ONE place expm1 is applied in the bulk file, and only to feed the shared helper's money-scale contract. (The TFM port series is built off `features.index`, which carries player_id; string-cast it with `to_str_index` too before `.reindex(ids)`.)
</note_on_tfm_helper>

```python
def test_tfm_parity_bulk(bulk_scored):
    import numpy as np
    from scoring.characterization.tfm_model import build_oracle_player_features
    from scoring.services.population import get_tfm_pipeline
    from scoring.services.financial_fit import _merge_tfm_feature_columns  # reuse the port's own merge helper
    from scoring.tests._parity_helpers import load_oracle_df, to_str_index, compare_tfm_series, write_mismatch_report

    pop, scored, cs_tp = bulk_scored
    # Merge the 4 upstream feature columns onto players_df (Pitfall 1: build_oracle_player_features
    # reads player_impact/compatibility_score/performance_score/role_pct off columns; absent -> NaN -> degraded).
    players_df = _merge_tfm_feature_columns(pop.players_df, scored, cs_tp)

    pipeline, feature_cols = get_tfm_pipeline()
    features = build_oracle_player_features(players_df, pop.transfers_df)
    for c in [c for c in feature_cols if c not in features.columns]:
        features[c] = np.nan
    X = features[feature_cols]
    port_log = pd.Series(pipeline.predict(X), index=features.index)          # RAW predict == LOG-scale == what the oracle stored
    port_log = port_log.where(features["_has_club_context"], np.nan)         # never fabricate a fee with no club context
    port_money = to_str_index(np.expm1(port_log))                            # to money AND string-indexed (features.index carries UUID player_id)

    oracle = load_oracle_df()
    ids = oracle.index                                                       # str
    mism = compare_tfm_series(oracle_log=oracle.loc[ids, "tfm"], port_money=port_money.reindex(ids))
    if len(mism):
        write_mismatch_report("bulk_tfm", mism)
    assert len(mism) == 0, f"{len(mism)} TFM mismatches (see _parity_reports/bulk_tfm.csv)"
```
