<objective>
Wire the natural-language search endpoint that ties every prior plan together: `POST /api/players/search/`. It orchestrates the 3-tier degradation — (tier 1) the provider-agnostic LLM parser, (tier 2) the deterministic keyword extractor when the LLM fails, (tier 3) the unfiltered list when even that yields nothing — always returning HTTP 200, always exposing `parsed_filters` + `fallback_used`, and always logging a `RecentActivity` "searched" row (completing the contract Phase 8 built for this exact producer).

Purpose: This is the user-facing surface for AI-01 (structured NL search) and AI-02 (graceful degradation, never an error). It composes the factory (Plan 02), the fallback + search service (Plan 03), and Phase 8's RecentActivity — introducing no new scoring/filter logic of its own.
Output: `PlayerSearchView`, the URL route, and a full DRF `APIClient` integration test suite covering all 3 tiers, RecentActivity logging, and the auth gate.
</objective>

       if not filters and fallback_used:
           filters = {}                                     # already empty; explicit for clarity
       # Note: a SUCCESSFUL-but-partial/empty tier-1 parse stays fallback_used=False
