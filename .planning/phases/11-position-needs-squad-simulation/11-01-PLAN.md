    ```python
    def classify_position_needs(club) -> dict:
        """PLAN-01 (11-01-PLAN.md): layers strong/weak/at-risk classification
        onto position_needs_aggregate's existing numbers. Never recomputes the
        underlying aggregation -- reuses it as-is (see module docstring / the
        Phase-10-vs-Phase-11 scoping decision)."""
        needs = position_needs_aggregate(club)
        result = {}
        for position, stats in needs.items():
            depth = stats["squad_depth"]
            avg_age = stats["avg_age"]
            expiring = stats["contracts_expiring_within_12mo"]
            if depth < 2:
                label = "weak"
            elif (avg_age is not None and avg_age > 30) or expiring >= depth / 2:
                label = "at-risk"
            else:
                label = "strong"
            result[position] = {**stats, "classification": label}
        return result
    ```
    Thresholds are LOCKED by 11-CONTEXT.md Decision "Strong/weak/at-risk classification": weak if `squad_depth < 2`; at-risk if `depth >= 2` AND (`avg_age > 30` OR `expiring >= depth / 2`); strong otherwise; checked in order weak → at-risk → strong. The `avg_age is not None` guard is mandatory (Player.age is nullable, so avg_age can be None; a None avg_age must fall through to the contract-expiry check, never raise). The `{**stats, "classification": label}` spread keeps the raw numbers in the output per 11-CONTEXT.md's "never hide the numbers behind a label" discretion note.
