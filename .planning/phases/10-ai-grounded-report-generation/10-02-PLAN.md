      `PLAYER_SECTIONS = ["Strengths", "Weaknesses", "Tactical Fit", "Financial Fit", "Best Use Case"]`
      `CLUB_SECTIONS = ["Recruitment Gaps", "Over-Aged Positions", "Financial Constraints"]`
      and a `SECTIONS_BY_TYPE = {"player_scouting_report": PLAYER_SECTIONS, "club_insights": CLUB_SECTIONS}`.
      A header-to-key helper that lowercases and replaces spaces/hyphens with underscores (e.g. "Best Use Case" -> "best_use_case", "Over-Aged Positions" -> "over_aged_positions").
    - `class AnthropicReportGenerator(ReportGenerator)` with `__init__(self, client=None): self._client = client`.
    - `generate(self, grounding, report_type)`:
      1. Resolve sections = SECTIONS_BY_TYPE[report_type]; raise ReportGeneratorError if report_type unknown.
      2. Build the prompt via a `_build_prompt(grounding, sections, ungrounded=None)` helper: instruct the model to write a scouting report / club insights strictly using ONLY the numbers present in the provided grounding JSON (embed `json.dumps(grounding)`), to NEVER invent or estimate any number, and to structure the response with EXACTLY these `## <Header>` markdown headers in this order. On the retry, `ungrounded` is the list of failed numbers — append a corrective instruction naming them and telling the model to remove/correct any figure not present in the grounding data.
      3. `client = self._client or anthropic.Anthropic(api_key=settings.ANTHROPIC_API_KEY)` (lazy, mirrors AnthropicNLQueryParser).
      4. Call `client.messages.create(model=settings.ANTHROPIC_REPORT_MODEL, max_tokens=1500, messages=[{"role":"user","content": prompt}])` — NO tools, NO tool_choice. Wrap in `try/except anthropic.APIError` -> raise ReportGeneratorError.
      5. Extract text: `"".join(b.text for b in response.content if getattr(b,"type",None)=="text")`.
      6. Parse sections via `re.split` on `^##\s+(<Header1>|<Header2>|...)\s*$` (re.MULTILINE, exact header set for this report_type). If any required section header is missing, raise ReportGeneratorError ("malformed report: missing section headers"). Map each header to its snake_case key.
      7. Run `validate_grounding(full_text, grounding)`. If non-empty (ungrounded numbers found): if this is the FIRST attempt, retry ONCE from step 2 passing the ungrounded list into `_build_prompt`; if it is the retry attempt, raise ReportGeneratorError ("report contained ungrounded numbers after retry").
      8. Return `GeneratedReport(narrative=<section dict>, grounding=grounding)`.
    Implement the retry as a bounded loop of at most 2 attempts (never unbounded).
