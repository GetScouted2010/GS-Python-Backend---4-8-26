<objective>
Build the shared import infrastructure (chunked CSV reader + import-report accumulator) and the first import command: Club derivation from Players.csv + Playstyles.csv. This establishes the reusable ETL pattern all later import plans follow.

Purpose: Clubs have no source file — they are derived. `Club.league` is the MODE of League across a team's player rows (49.6% of clubs have ambiguous league values, so this path is common, not rare — RESEARCH.md). `Club.playing_style` only covers ~239/1,059 clubs; the ~77% null rate is expected and MUST be stated in the report so a reviewer does not mistake it for a bug (DATA-05). The ImportReport class built here is reused by Plans 05-09.
Output: core/import_utils.py, the club import command, and its tests.
</objective>
