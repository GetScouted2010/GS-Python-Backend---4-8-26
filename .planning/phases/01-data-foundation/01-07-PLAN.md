<objective>
Normalize the 9 wide Compatibility Scores matrices (UniqueID, Position, ~212 club columns each — ~8.1M values total) into the long PlayerClubCompatibility table, resolving each club column header to a Club FK where possible and preserving unresolved headers as club=null + club_name_raw.

Purpose: DATA-03 (position-aware player-club data, queryable both directions for Phase 11/12 PLAN-02/PLAN-04). This is the highest-volume table in the phase; the wide shape cannot be sorted by the ORM, so it must be normalized at import time. The `(player, club_name_raw)` unique key (not `(player, club)`) is mandatory because club is null for unresolved headers and Postgres treats multiple NULLs as non-conflicting (RESEARCH.md Open Question 2).
Output: import_compatibility_scores.py + players/tests/test_compatibility.py.
</objective>
