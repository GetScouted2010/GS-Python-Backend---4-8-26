From scoring/characterization/impact.py — `add_player_impact(df) -> pd.DataFrame` attaches to every row:
  - "Player Impact"           (the final 0-100 RMM value, or NaN)
  - "Player Impact Positive"  (sum of positive component contributions)
  - "Player Impact Negative"  (sum of negative component contributions)
  - "Impact Reliability"
  - "Impact Comp - <name>"    (one column per position-specific sub-component; names differ by position)

Position-keyed component names (from impact.py; the breakdown is inherently position-dependent — faithful, not a bug):
  GK: shot_stopping, command, distribution, buildup_support
  CB: defensive_actions, duel_dominance, aerial, reading, buildup
  LB/RB: defending, progression, chance_creation, control, duel_work
  CM: ball_progression, control, creation, ball_winning, carrying
  DMF: ball_winning, control, progression, distribution, creation
  AMF: creation, final_third_progression, scoring_threat, carrying, connection
  LW/RW: dribbling, creation, threat, progression, duel_value
  CF: finishing, box_threat, chance_creation, progression, duel_value

From scoring/services/population.py (Plan 01): `reconstruct_population()`, and `null_with_reason(field, code)` from scoring/exceptions.py.
players_df "player_id" holds Player UUID objects; the URL id arrives as a string — coerce both to str before matching.

    Create `get-scouted-be/scoring/services/rmm.py` with:

    `rmm_breakdown_from_scored(row)` — takes an already-scored pandas Series (a row from add_player_impact's output) and returns:
    ```python
    import pandas as pd
    from scoring.exceptions import null_with_reason
    impact = row["Player Impact"]
    if pd.isna(impact):
        return null_with_reason("rmm", "insufficient_player_data")
    comp_cols = [c for c in row.index if c.startswith("Impact Comp - ")]
    return {
        "rmm": float(impact),
        "positive": None if pd.isna(row.get("Player Impact Positive")) else float(row["Player Impact Positive"]),
        "negative": None if pd.isna(row.get("Player Impact Negative")) else float(row["Player Impact Negative"]),
        "components": {c.removeprefix("Impact Comp - "): float(row[c]) for c in comp_cols if pd.notna(row[c])},
        "reliability": None if pd.isna(row.get("Impact Reliability")) else float(row["Impact Reliability"]),
    }
    ```

    `get_rmm(player_id)` — high-level entry:
    ```python
    from django.http import Http404
    from scoring.characterization.impact import add_player_impact
    from scoring.services.population import reconstruct_population
    pop = reconstruct_population()
    scored = add_player_impact(pop.players_df.copy())   # NOT compute_rmm_column — need components
    scored["_pid_str"] = scored["player_id"].astype(str)
    match = scored[scored["_pid_str"] == str(player_id)]
    if match.empty:
        raise Http404(f"Player {player_id} not found")
    return rmm_breakdown_from_scored(match.iloc[0])
    ```
    Do NOT call `compute_rmm_column` anywhere in this module — it discards the component breakdown SCORE-05 requires.
